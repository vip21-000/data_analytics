# Data Analytics

Practical assignments for the Data Analytics course. Each lab is a Jupyter notebook run in Google Colab and lives in its own folder with a separate README.

## Labs

| # | Topic | Folder |
|---|-------|--------|
| 1 | Analysis of Dota 2 hero picks: filtering, aggregation, merge, bar chart | [lab1](lab1/README.md) |
| 2 | Pandas: working with tables (DataFrame, `loc`/`iloc`, filtering, sorting) | [lab2](lab2/README.md) |

## Tech stack

- Python 3
- Pandas, NumPy
- Matplotlib
- Google Colab

## How to run

1. Open the notebook of the needed lab in [Google Colab](https://colab.research.google.com) (File → Upload notebook, or open it from GitHub).
2. Upload the data files listed in the lab's README.
3. Run all cells (Runtime → Run all).
