# Робота 2. Pandas: робота з таблицями

## Мета

Освоїти основні структури Pandas (`DataFrame` та `Series`), навчитися імпортувати дані з файлів, переглядати їх, виконувати індексацію, фільтрацію та сортування табличних даних.

## Дані

`coffee_sales.csv` — продажі кав'ярні, понад 4 000 записів, 6 колонок:

| Колонка | Опис |
|---------|------|
| `date` | дата продажу |
| `datetime` | дата й час продажу |
| `cash_type` | тип оплати (`card` / `cash`) |
| `card` | анонімізований ID картки (порожньо для готівки) |
| `money` | сума транзакції |
| `coffee_name` | назва напою |

## Що робить ноутбук

1. Створює `DataFrame` зі словника (таблиця книг).
2. Зчитує CSV у `DataFrame` та оглядає його: `head()`, `tail()`, `info()`, `describe()`, `columns`.
3. Вибирає дані через `loc` та `iloc`.
4. Фільтрує рядки булевими масками (`cash_type == 'card'`, `Latte` і `money > 30`).
5. Сортує за `datetime` (після `pd.to_datetime`) та за `money`.
6. Зберігає відфільтрований і відсортований результат у CSV.
7. Додаткове завдання: функція, що рахує записи за категорією через `value_counts()` і сортує їх за спаданням.
8. Відповіді на питання для самоперевірки.

## Як запустити

1. Завантажте `coffee_sales.csv` у корінь Google Диска (`MyDrive`).
2. Відкрийте `lab2_pandas_tables.ipynb` у Google Colab.
3. Запустіть усі комірки та надайте доступ до Google Диска, коли з'явиться запит.

Якщо файл має іншу назву чи розташування, змініть змінну `PATH` у комірці із завантаженням даних.

## Що відпрацьовано

`DataFrame` і `Series`, `read_csv` / `to_csv`, `loc` / `iloc`, булеві маски з `&`, `sort_values`, `to_datetime`, `value_counts`.
