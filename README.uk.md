# Аналітика даних

Практичні роботи з курсу «Аналітика даних». Кожна робота — це Jupyter-ноутбук для Google Colab, який лежить у власній папці з окремим README.

## Роботи

| № | Тема | Папка |
|---|------|-------|
| 1 | Аналіз виборів героїв Dota 2: фільтрація, агрегація, об'єднання таблиць, стовпчаста діаграма | [lab1](lab1/README.uk.md) |
| 2 | Pandas: робота з таблицями (DataFrame, `loc`/`iloc`, фільтрація, сортування) | [lab2](lab2/README.uk.md) |

## Як запустити

1. Відкрийте ноутбук потрібної роботи в [Google Colab](https://colab.research.google.com) (Файл → Завантажити ноутбук, або відкрити з GitHub).
2. Завантажте файли з даними, перелічені в README роботи.
3. Запустіть усі комірки (Середовище виконання → Виконати все).
